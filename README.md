# first-try

我的第一个 C 语言 + Git + GitHub 练习项目。

## 环境要求

- GCC (MinGW-w64)
- 仅使用 C 标准库

## 编译运行

```powershell
gcc -Wall -Wextra -g main.c -o main.exe
.\main.exe
```

在 VS Code 里也可以直接按 `Ctrl+Shift+B` 一键编译。
